How it works

Each game is predicted as a point margin from team strength (a margin-of-victory Elo rating and a recency-weighted net rating per 100 possessions), home court, and rest (days off, back-to-backs, three games in four nights). The margin becomes a win probability using the model's historical error.

The rest of the league schedule is simulated 10,000 times. Each simulation shifts every team's strength by a random amount reflecting how uncertain we are about it, then plays out every game, applies tiebreakers (head-to-head, division winner, conference record), and runs the play-in.

The model is trained on every regular-season game since 2015-16 and tested walk-forward: each test season is predicted using only data from before it.
